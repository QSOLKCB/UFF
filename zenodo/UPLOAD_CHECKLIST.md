# Zenodo upload checklist - UFF-SLFA v1.0.0

1. Merge the reviewed pull request.
2. Create GitHub tag and release `uff-slfa-v1.0.0`.
3. Attach `papers/UFF_SLFA_v1.0.0.pdf` and `papers/UFF_SLFA_v1.0.0.md`.
4. Include the release source archive generated by GitHub.
5. Copy metadata from `zenodo/UFF_SLFA_v1.0.0.json`.
6. Use Apache-2.0 for the software record.
7. Verify the paper and repository-authored upload files covered by
   `zenodo/UFF_SLFA_v1.0.0_SHA256SUMS.txt`.
8. After tagging, download the exact GitHub-generated source archive, calculate
   its SHA-256 separately, record that digest in the release notes or deposition
   log, and verify the uploaded archive against that post-tag digest. The
   pre-release checksum file cannot cover an archive that does not yet exist.
9. After publication, add the minted DOI to the release notes and paper metadata in a follow-up commit.

Do not claim that the record applies to a specific target framework until a separate frozen claim contract and catalogue receipt have been deposited.
