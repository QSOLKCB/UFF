# UFF-SLFA v1.0.0 - Release notes

UFF-SLFA turns celestial-node claims into frozen, replayable catalogue tests.

## Added

- Machine-readable `uff.sky-lattice-claim.v1` contracts.
- Explicit rejection of node-targeted selection as confirmatory evidence.
- Independent-catalogue and holdout enforcement.
- RA-shift, Haar-uniform SO(3), and stratified-label null models.
- Weighted inside-versus-outside anomaly-rate contrasts.
- Finite empirical permutation p-values and Holm family-wise correction.
- TFT-derived proper-rotation, Gram-matrix, and pairwise-angle invariance checks.
- Complete node tables retaining failed and untestable nodes.
- Recipe, observations, node CSV, and SHA-256 manifest bundles.
- Independent integrity verification and numerical replay.
- Zenodo-ready methods paper, metadata, checklist, and checksums.

## Scientific boundary

UFF-SLFA tests only the exact catalogue-level claim frozen in a contract. It does not convert catalogue diagnostics into physical objects, prove a vacuum ontology, or require critics to show that no later modified theory can ever be written.
